# Mellomey Dzaklidzie · Portfolio

Personal portfolio built with React and Vite. Live at **https://mellomeydzak-ai.github.io/**

## Edit and publish

1. Change your details, skills or projects in `src/data.js`.
2. Preview locally: `npm install`, then `npm run dev`.
3. Build: `npm run build` (outputs to `docs/`, which GitHub Pages serves).
4. Commit and push. The live site updates in a minute or two.

To add a screenshot for a project card: `npm run shot -- https://example.com mysite`, then set `image: 'projects/mysite.jpg'` in `src/data.js`.

## CV

The downloadable CV is `public/Mellomey-Dzaklidzie-CV.pdf`. To change it, edit `cv/cv.html`, then run `npm run cv` and `npm run build`.
The "My Journey" tree on the site comes from `experience` in `src/data.js`.
